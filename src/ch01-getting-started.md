# Chapter 1: Getting Started with Nova

Nova is engineered to unite the memory safety and ergonomics of Rust, the raw execution speed and bare-metal hardware control of C/C++, and the mathematical correctness guarantees of SMT-backed Refinement Types.

## Installation

```bash
# Linux & macOS
curl -fsSL https://raw.githubusercontent.com/novasystems-dev/nova/master/install.sh | bash

# Windows PowerShell
irm https://raw.githubusercontent.com/novasystems-dev/nova/master/install.ps1 | iex
```
